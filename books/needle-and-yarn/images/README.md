# Illustration Authority

This directory is the canonical illustration workspace for the revised six-chapter edition.

## Structure
- character-authority/ — approved Leola, Needle, Yarn, and recurring basket-family identity references
- chapter-01/ through chapter-06/ — chapter illustration assets
- illustration-manifest.json — asset-to-scene mapping and approval state

Existing historical artwork remains in the repository and must be classified KEEP / ENHANCE / NEW before replacement.
