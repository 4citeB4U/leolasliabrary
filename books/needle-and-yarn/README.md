# Needle & Yarn: A Love Stitched in Time

## Canonical eBook workspace

This directory is the publication workspace for the revised six-chapter edition of **Needle & Yarn: A Love Stitched in Time** by Leola "Sister" Lee.

### Publication structure

- `metadata.json` — machine-readable book metadata
- `front-matter.md` — preserved dedication and foreword from the original repository edition
- `manuscript/` — locked revised six-chapter manuscript
- `documentation/` — editorial history, provenance, human/AI contribution record, and revision rationale
- `images/` — future canonical illustration manifest/assets
- `exports/` — generated EPUB/PDF publication artifacts (not source authority)

### Authority rule

The manuscript source is authoritative over generated PDF/EPUB exports. Generated exports are publication artifacts, not editing authority.

The original repository book implementation remains historical evidence and is not overwritten by this workspace.
