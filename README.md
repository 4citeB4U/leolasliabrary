# Leola's Learning Library

Leola's Learning Library is an interactive 3D clay-style web library for illustrated eBooks, crochet learning, games, video-learning routes, and a growing publishing catalog.

**Live site:** https://4citeb4u.github.io/leolasliabrary/

## Current verified state

The September 29, 2026 release gate verifies:

- a bootable Three.js 3D library world;
- a fully 3D Milwaukee waterfront with no static skyline panorama in the scene;
- a modeled waterfront museum / boathouse composition and five additional 3D background buildings;
- four animated harbor sailboats;
- first-person and third-person camera switching;
- the complete six-chapter *Needle & Yarn: A Love Stitched in Time* reader;
- chapter-specific story illustrations and page-turn presentation;
- the current training route and five-room Game House catalog;
- no uncaught browser errors in the acceptance run.

The browser world is rendered with real Three.js geometry. Blender source files, GLB exports, previews, and native-execution receipts are preserved for continued 3D asset development.

## Local development

Requirements: Node.js 22.x and a modern Chromium-based browser.

```powershell
npm ci
npm test
npm run build
npm run test:browser
```

To view the generated release locally:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory public
```

Then open `http://127.0.0.1:4173/`.

## Release contract

`npm run build` creates a deterministic `public/` directory. That directory is generated output and is intentionally excluded from Git.

`npm run test:browser` verifies the current product rather than retired reception-screen selectors. Its present scope includes the 3D waterfront, moving sailboats, camera modes, illustrated reader, training route and Game House catalog.
## 3D and Blender policy

The live waterfront must remain spatial 3D geometry. Static 2D skyline or waterfront billboards are not an acceptable substitute for the clay world.

The repository keeps:

- editable `.blend` source assets;
- web-ready `.glb` exports;
- preview renders used for review;
- Blender receipt bundles recording native execution.

Local Blender autosaves (`*.blend1`) and connector stderr scratch files are ignored.

## Legacy and recovered assets

This repository contains older hash-named HTML, JavaScript and image assets recovered from earlier versions. Some remain reachable from legacy routes or are referenced by canonical content. Do not delete them solely because their names look generated. Remove or relocate a legacy asset only after a reference audit proves it is unused.

## Books and publishing

The featured reader currently exposes Leola's book catalog and binds canonical content at runtime. *Needle & Yarn* is presented as a six-chapter illustrated story. Publishing metadata lives under `content/publishing/` so additional titles can be added without hard-coding a new storefront structure.

## Evidence

Release claims are accepted only after execution. The normal gate is:

1. `npm test`
2. `npm run build`
3. `npm run test:browser`
4. inspect the rendered waterfront
5. commit and push only the verified source/artifacts
